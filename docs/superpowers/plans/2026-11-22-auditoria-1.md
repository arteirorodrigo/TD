## Global Constraints
- Não mexer: Etérea (raio de revelação), imunidade a físico, tela de fim (descartados).
- "Trocar uma pedra" só aparece com a sorte no nível máximo; preços 50, 100, 200 na mesma rodada.
- Infinito: depois da 50, repetir as ondas 26–50; ciclo c ≥ 1 → vida × 3^c, armadura + 5·c, ouro × (1 + c).
- Chefes: vida do chefe 50 × 10; chefes 20 e 30 × 2.
- Festa do dragão reaproveita partículas existentes; toque pula.
- Português simples nos textos; `npm test` verde; fotos de verificação em computador e 640×360.

## Review Focus
- Partida de 100+ ondas não cresce memória (geometrias descartadas; compartilhadas não).
- Trocar pedra fora da fase de escolha, sem ouro, ou antes da sorte máxima → recusado.
- Aviso de onda especial no modo infinito (ex.: fase 58 = base 33) aparece certo.
- Dicas da primeira partida não voltam depois de vistas; armazenamento bloqueado não quebra.
- Celular deitado 640×360: mapa visível e botão Manter/Combinações acessíveis sem rolar.

### Task 1 (J1): Jogo leve
- `disposeGroup` também descarta geometrias, exceto as compartilhadas (`rockGeos`, `pedestalGeo` e outras criadas no construtor → registrar num `Set` `this.sharedGeos`).
- Barra de vida: reaproveitar `Quaternion`/`Vector3` temporários (sem `new` por quadro).
- `setPixelRatio(min(dpr, telaPequena ? 1.5 : 2))`.
- Cartão de inimigo: se o mesmo inimigo continua selecionado, atualizar só barra, texto da vida e efeitos.
- Verificação: script de 30 ondas no navegador (`renderer.info.memory.geometries` estável).

### Task 2 (J5): Infinito 26–50 e chefes mais fortes
- `waveFor(level)`: c = ciclo; base = level ≤ 50 ? level : 26 + ((level − 51) mod 25); c = level ≤ 50 ? 0 : 1 + floor((level − 51) / 25). Exportar `baseLevelOf(level)`.
- Vida de chefes: multiplicador `BOSS_HP_MULT = {20: 2, 30: 2, 50: 10}` aplicado no tipo.
- Testes: 51 → base 26 c1; 75 → base 50 c1 (chefe); 76 → base 26 c2; chefe 50 com vida ×10; atualizar testes antigos de 51/100/101.

### Task 3 (J4): Trocar uma pedra
- `Game#rerollCost()` → null se sorte < máxima ou fase ≠ 'choose'; senão 50·2^n (n = trocas nesta rodada). `Game#reroll(uid)`: pendente, paga, sorteia nova escama (`rollGem`), n++. Zera n em `finishRound`.
- UI: no cartão de escama pendente, botão "Trocar esta pedra (X ouro)" só quando `rerollCost()` ≠ null.
- Testes: recusa sem sorte máxima; recusa sem ouro; custa 50, 100, 200; muda a escama; reseta na rodada seguinte.

### Task 4 (D2): Aviso de ondas especiais
